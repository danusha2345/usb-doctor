# Правила проекта

- Отвечать и вести проектную документацию по-русски.
- Начинать с README.md и относящихся к задаче разделов PLAN.md.
- Основной VCS — Jujutsu (`jj status`, `jj diff`, `jj log`, `jj git push`).
- Репозитории публичные; commit/push/release — в согласованном объёме.
- Для навигации по исходникам сначала CodeGraph (`codegraph explore --path .`).
- Проверять `codegraph status . --json`; синхронизировать при необходимости.
- При отсутствии кодовых символов читать документы/исходники через rg; не индексировать родительские каталоги.
- Наблюдения, гипотезы и рекомендации разделять. Неизвестные поля не считать ошибками.
- Секреты и персональные диагностические данные не включать в Git и логи.
- Scratch — .scratch/; крупные артефакты свыше 50 MB — ~/storage.
- Сборка/фикстуры не заменяют реальную проверку Windows/Android и устройств.

- Интерфейс плотный: компактные строки и небольшие отступы, без крупных декоративных карточек.
- Галочки меняют только представление/экспорт; никогда не ограничивать ими сбор данных.
