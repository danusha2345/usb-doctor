# USB Глаз / USB Eye 0.6.1 alpha

Добавлен выбор Русский / English с сохранением в inventory.json. Старые настройки
загружаются с русским языком. Переключение применяется без пересбора снимка; ключи
полей, порядок/ширина колонок и выбор данных не зависят от языка. Название окна
переключается USB Глаз / USB Eye; повторный запуск активирует окно в обеих локалях.

Переводится слой представления: меню, диалоги, подсказки, колонки, группы полей,
диагностические пояснения. Каталог src/translations.json загружается один раз.
Исходные снимки, JSON/HTML export и данные Windows не переписываются переводом.
Технические API names/IDs и собственные имена устройств остаются исходными.

«Недоступно запросов» заменено на «Подключено · часть данных недоступна».
Подсказка указывает количество запросов и путь к подробностям; ошибка получения
дополнительных данных не представляется как неисправность устройства. Проблема
Windows и неуспешный статус порта по-прежнему имеют приоритет.

Проверки: 84 теста Linux, 86 тестов Windows. Проверены миграция
настроек, сохранение языка, независимость снимков/ID, вложенные переводы и все
шаблоны каталога. Clippy Linux/Windows без предупреждений.

Windows GUI: проверены RU → EN → перезапуск → RU, английские колонки, окно выбора
полей и история, сохранение порядка колонок, один экземпляр. Снимки интерфейса
с реальными устройствами добавлены по явному запросу пользователя; серийные номера
и Instance ID на них не показаны.

Публикация: только usb-glaz.exe без архива и CLI; двуязычный README, реальные
скриншоты Windows RU/EN, лицензии и SHA256SUMS.txt. Тег v0.6.0-alpha сохраняет
предыдущий код; 0.6.1 включает двуязычный интерфейс.
