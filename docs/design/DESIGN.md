# Интерфейс USB Глаз 0.6.1

Основной экран — компактная таблица подключённых USB-устройств. Группировка по
хабам переключается; ветки можно свернуть. Строки 23 px, встроенный Roboto Condensed
13 px. Сведения выбираются галочками, но сбор никогда не ограничивается их выбором.

- Заголовки перетаскиваются для изменения порядка; границы — для изменения ширины.
- Полосы прокрутки закреплены у границ видимой области. Заголовок не прокручивается
  по вертикали; горизонтальное смещение заголовка и тела синхронизировано.
- Изменения USB подсвечиваются 5 секунд. Автопрокрутка к изменению отключается.
- Светлая, тёмная и системная темы; Русский / English с сохранением выбора.
- Клик по строке открывает поля, сравнение и дескрипторы; контекстное меню копирует
  идентификаторы. У обрезанного текста одна подсказка.
- Недоступные дополнительные сведения не считаются доказательством неисправности.
