# Проверка прототипа интерфейса

Дата: 2026-09-27. Среда: Google Chrome / Playwright на Linux.
Объект: prototype.html, prototype.css, prototype.js; только вымышленные данные.

## Пройденные проверки

19 проверок browser smoke завершились успешно:

- Второй пример сравнения открывается после подтверждения, что сравнивается то же устройство; демонстрационный режим обозначен отдельно.
- Сравнение SSD показывает смену 480 Мбит/с → 5 Гбит/с в синтетических снимках.
- Открытие второго примера отмечено как действие демо, а не реальное USB-событие.
- Журнал клавиатуры не содержит действие, выполненное для SSD.
- Клавиатура 12 Мбит/с не получает ложное предупреждение о медленном соединении.
- Недоступные сведения не обозначаются доказанной неисправностью.
- Для отключённого телефона данные помечены как исторические.
- Для отсутствующего устройства недоступно создание второго примера сравнения.
- Поиск: пустая выдача и фильтрация списка.
- В подробностях использовано точное имя DeviceIsOperatingAtSuperSpeedOrHigher.
- Просмотр экспорта содержит demo=true, выбранное устройство и скрытые идентификаторы.
- JSON действительно скачан и дополнительно разобран парсером.
- На ширине 1440, 900 и 600 CSS px нет горизонтального переполнения страницы.
- Клавиатурная навигация из поиска переходит к кнопке устройства.
- За время финального прогона нет JavaScript exceptions и внешних сетевых запросов.

Отдельно: `node --check docs/design/prototype.js` прошёл.
Просмотрены изображения основного экрана на ширине 1440/900 и сравнения на 1440.
В первом просмотре обнаружен запрос отсутствующего favicon; добавлен data URI,
финальный прогон выполнен после исправления. Скриншоты сохранены рядом:

## Границы проверки

Это проверка браузерного прототипа, не нативного Windows-приложения. Сбор USB,
оборудование, Windows API, нагрузка, Narrator/NVDA и реальное DPI-масштабирование
Windows не проверены. Resize браузера не заменяет DPI-тест. Полного аудита WCAG нет.
Артефакты browser smoke и скачанный JSON находятся локально в игнорируемой .scratch/.

Для повторного просмотра открыть prototype.html в браузере или запустить:

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory docs/design
```

Затем перейти на http://127.0.0.1:8766/prototype.html .
